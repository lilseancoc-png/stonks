# August 2026

- **New free Alt Data desk: Central-bank gold.** The daily bake now checks the World Gold Council's public official-reserves dashboard and latest Gold Demand Trends report, keeping quarterly estimated global net purchases separate from disclosed country holdings. The page shows latest and trailing-four-quarter demand, q/q and y/y changes, reported holdings by country, gold's share of reserves, 3-month and 12-month changes in both tonnes and percent, buyer/seller leaderboards, selectable country history, source dates, and a searchable/sortable all-country table. Each source carries last-good independently and the UI explains why reported country changes do not reconcile to estimated global demand. `lib/central-bank-gold.mjs`, `scripts/build.mjs`, `scripts/render/{html,app-js,styles-css}.mjs`, `docs/site-logic.md`.
